# Asset credits — ELOVE Lab Escape

The playable game is **true 2D** (Canvas 2D) with procedural HD-pixel sprites. Legacy GLTF files under `assets/` are kept on disk for reference only and are **not loaded** by the game.

## Procedural / original (this project) — active

- **Player** — HD-pixel cat-girl (ears, pink dress, cream skin) with idle / walk / slash / hurt / success frames
- **Cyborg enemies** — metallic purple/cyan chassis + glowing eyes; headless / attack frames
- Lab tiles — floor, walls, pod, closet, console, hidden button, door, exit pad, decor
- Loot — sword + eye-key sprites
- Glow markers, slash arc, force-warp ring, hit sparks

Palette: pink / cyan / purple / gold.
